### 📘 Aula 06 — Estruturas de Repetição

Nesta aula foram estudadas as **estruturas de repetição em linguagem C**, utilizadas para executar um determinado bloco de código várias vezes de acordo com uma condição ou quantidade definida.

Durante a aula, foram apresentados os comandos `for`, `while` e `do...while`, além de exercícios práticos para aplicar esses conceitos.

**Conteúdos praticados:**

- 🔄 Estruturas de repetição
- `for`
- `while`
- `do...while`
- Contadores e acumuladores
- Condições de repetição
- Validação de dados
- Soma e média de valores
- Comparação de valores
- Repetição controlada por quantidade
- Repetição controlada por condição

### 🎯 Objetivo da aula

Praticar a utilização das estruturas de repetição e compreender quando utilizar cada uma delas:

- **`for`** → quando a quantidade de repetições é conhecida.
- **`while`** → quando a repetição depende de uma condição.
- **`do...while`** → quando o código precisa ser executado pelo menos uma vez antes da verificação da condição.

A aula também permitiu aplicar essas estruturas em situações práticas envolvendo cálculos, validações, médias, somas e controle de tentativas.
