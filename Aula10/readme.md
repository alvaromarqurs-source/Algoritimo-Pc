# 📘 Aula 10 — Funções, Ponteiros e Estruturas em C

Esta aula apresenta conceitos importantes da linguagem C, com foco na organização do código por meio de funções, utilização de ponteiros e criação de estruturas para armazenar e manipular dados.

## 📚 Conteúdos abordados

- **Funções:** criação e utilização de funções para organizar e reutilizar códigos.
- **Ponteiros:** introdução à manipulação de endereços de memória e passagem de valores por referência.
- **Struct:** criação de estruturas para agrupar diferentes tipos de dados.
- **Arrays de estruturas:** armazenamento e manipulação de vários registros.
- **Matrizes:** utilização de matrizes para organizar e processar conjuntos de dados.
- **Laços de repetição:** utilização de `while` e `for` para executar operações repetidamente.
- **Menu interativo:** criação de sistemas com opções para cadastrar, consultar e listar informações.

## 💻 Exercícios desenvolvidos

### Exercício 01 — Cálculo de Frete
Criação de funções para calcular o valor do frete com base no peso informado, permitindo realizar vários cálculos em sequência.

**Conceitos:** funções, parâmetros, retorno de valores e laços de repetição.

### Exercício 02 — Troca de Valores
Desenvolvimento de uma função para trocar os valores de duas variáveis utilizando ponteiros.

**Conceitos:** ponteiros, endereços de memória e passagem por referência.

### Exercício 03 — Média de Alunos
Programa que recebe duas notas, calcula a média e informa se o aluno foi aprovado ou reprovado.

**Conceitos:** funções, parâmetros, retorno de valores e estruturas condicionais.

### Exercício 04 — Cálculo de Área
Desenvolvimento de uma função para calcular a área de um espaço utilizando largura e comprimento.

**Conceitos:** funções, parâmetros e operações matemáticas.

### Exercício 05 — Cadastro de Aluno
Utilização de `struct` para armazenar o RGM e as notas de um aluno, além de calcular e apresentar sua média.

**Conceitos:** estruturas, funções e ponteiros.

### Exercício 06 — Consulta de Alunos
Criação de um programa que armazena os dados de três alunos e permite consultar suas médias por meio do RGM.

**Conceitos:** `struct`, arrays de estruturas, ponteiros e estruturas de repetição.

### Exercício 07 — Sistema Acadêmico
Desenvolvimento de um sistema acadêmico com menu interativo, permitindo cadastrar alunos, consultar informações pelo RGM e listar os alunos cadastrados.

**Conceitos:** funções, `struct`, arrays, ponteiros, `switch case` e organização de programas.

### Desafio — Monitoramento de Energia
Desenvolvimento de um programa para analisar o consumo de energia de quatro laboratórios durante sete dias da semana.

O sistema calcula o consumo total, as médias de cada laboratório, identifica o dia e o laboratório com maior consumo e contabiliza os registros acima de 100 kWh.

**Conceitos:** matrizes, funções, ponteiros, arrays, laços de repetição e análise de dados.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Visual Studio Code
- Compilador GCC

## 🎯 Objetivo da aula

Praticar a criação de programas mais organizados e funcionais em C, compreendendo como utilizar funções, ponteiros, estruturas e matrizes para desenvolver soluções que trabalham com diferentes tipos de dados.
